A token launch radar: it reads a sealed DefiLlama snapshot of every protocol, finds the ones that still record no token and are not a wrapped or staked product of one that trades, ranks them by what their launch would be worth, and serves the board as a web dashboard with a detail view and a farm plan for each protocol. Built by an AI agent for make.fun's "Build the best token launch radar" bounty, $1,325 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
